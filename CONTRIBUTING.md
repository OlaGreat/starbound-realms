# Contributing to Starbound Realms

Thanks for your interest in contributing. This project is open to contributors of all skill levels.

## Where to start

- Browse [`good first issue`](https://github.com/OlaGreat/starbound-realms/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) for beginner-friendly tasks
- Browse [`help wanted`](https://github.com/OlaGreat/starbound-realms/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22) for larger tasks

## Areas to contribute

| Area | Language | Location |
|---|---|---|
| Smart Contracts | Rust | `contracts/` |
| TypeScript SDK | TypeScript | `sdk/` |
| Frontend | React / TypeScript | `frontend/` |
| Backend / Indexer | Node.js / TypeScript | `backend/` |
| Documentation | Markdown | `docs/` |
| Scripts | Bash | `scripts/` |

## Setup

See the [Getting Started](README.md#getting-started) section in the README.

## Pull Request Guidelines

- One feature or fix per PR
- Reference the issue your PR addresses (`Closes #123`)
- Keep PRs focused — avoid unrelated changes
- Add tests where applicable
- Ensure CI passes before requesting review

## Questions?

Open a [Discussion](https://github.com/OlaGreat/starbound-realms/discussions) or comment on the relevant issue.
